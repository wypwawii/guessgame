# Guess Game

Консольная игра "Угадай число" на Go.

Игроку нужно угадать случайное число за ограниченное количество попыток. Доступны разные уровни сложности, подсказки по расстоянию до числа, история попыток и сохранение результатов в `results.json`.

## Запуск

```bash
go run main.go
```

## Возможности

-   Easy: 1–50, 15 попыток
-   Medium: 1–100, 10 попыток
-   Hard: 1–200, 5 попыток
-   Подсказки "Горячо / Тепло / Холодно"
-   История предыдущих попыток
-   Проверка некорректного ввода
-   Повторный запуск игры
-   Сохранение результатов в `results.json`
-   Цветной вывод в терминале
